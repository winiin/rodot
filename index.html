DEVICE LINK / 06

Подключение робота

Подключи совместимый последовательный интерфейс и получай телеметрию. Совместимость зависит от платы и браузера.

!

Для реального управления движением требуется знать Bluetooth-модуль и команды прошивки. Этот интерфейс не отправляет случайные команды и не притворяется подключённым к роботу.

SERIAL CONNECTION
⌁

USB / Serial

Подключение Arduino через USB-последовательный порт в браузерах с поддержкой Web Serial (обычно Chrome или Edge на компьютере).

DATA PROTOCOL

Формат телеметрии

Для автоматического чтения отправляй из Arduino одну JSON-строку на каждое измерение, завершая её переводом строки:

{
  "soil": 42,
  "temperature": 23.5,
  "humidity": 58.2
}

Поля необязательны. Можно добавить timestamp в формате ISO. Значения должны быть числами. Это формат, который ожидает веб-сайт; прошивку робота нужно настроить отдельно.

ⓘ

Web Serial подключается к USB-порту, а не напрямую к любому Bluetooth-модулю. Некоторые модули Bluetooth Classic (например, SPP) браузером Web Bluetooth не поддерживаются. Для точной Bluetooth-интеграции нужны модель модуля, UUID/профиль связи и формат прошивки.
