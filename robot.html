AETHER / ROBOTICS PROJECT

Наш робот.
Наш способ исследовать.

Мобильная робототехническая платформа для изучения условий выращивания растений. Робот перемещается на гусеничном шасси, а команды движения передаются по Bluetooth с контроллера, который реагирует на наклон руки.

Гусеничная платформаArduino NanoMPU6050Bluetooth
MOBILE TRACKED PLATFORM · CONCEPT VIEW
01 / PURPOSE

Для чего создан робот

Проект объединяет мобильную платформу и исследование окружающей среды. Его задача — помогать наблюдать за условиями, в которых растут растения.

01 — MOVEMENT

Перемещение по участку

Гусеничное шасси служит мобильной основой для движения по исследуемой поверхности.

02 — CONTROL

Управление наклоном руки

Контроллер считывает наклон руки и преобразует его в команды движения.

03 — RESEARCH

Изучение условий

Проект предназначен для мониторинга влажности почвы и параметров микроклимата.

02 / CONTROL SYSTEM

Как передаётся команда

Схема показывает принцип управления, описанный в материалах проекта.

01

Наклон руки

Пользователь наклоняет контроллер вперёд, назад или в сторону.

02

MPU6050

Акселерометр и гироскоп фиксируют изменение положения.

03

Arduino Nano

Микроконтроллер обрабатывает показания и формирует команду.

04

Bluetooth

Команда передаётся по беспроводному Bluetooth-соединению на робота.

03 / MAIN ELEMENTS

Основные элементы проекта

Здесь перечислены только узлы, которые подтверждены описанием вашего проекта.

ELECTRONICS

Arduino Nano

Контроллер, который обрабатывает данные датчика наклона и формирует команды.

MOTION SENSOR

MPU6050

Модуль акселерометра и гироскопа в ручном контроллере.

COMMUNICATION

Bluetooth

Текущий беспроводной канал передачи команд между контроллером и роботом.

MOBILITY

Гусеничное шасси

Механическая основа мобильной платформы.

DRIVE

Двигатели и драйвер

Приводная часть обеспечивает движение платформы по командам управления.

PROJECT GOAL

Мониторинг среды

Направление проекта — исследование почвы и микроклимата для оценки условий выращивания растений.

Сейчас: Bluetooth

На данный момент для связи с роботом используется Bluetooth. GPS, Wi-Fi, USB-подключение и другие каналы связи на этой странице не заявляются как реализованные функции.
