OUR TECHNOLOGY / 01

Designed for the
real world.

В основе проекта — мобильная платформа с гусеничным приводом и электронной системой управления. Визуальная схема ниже показывает общую компоновку, а не точную сборочную документацию.

01 — CONTROL UNIT

Arduino Nano обрабатывает данные датчика и формирует команды движения.

02 — MOTION INPUT

MPU6050 определяет наклон ручного контроллера.

03 — TRACKED DRIVE

Гусеничная платформа, двигатели и драйвер обеспечивают перемещение.

HOW IT WORKS / 02

From gesture
to movement.

Команда проходит несколько последовательных этапов: от движения руки до реакции мобильной платформы.

01 / INPUT

Наклон руки

Пользователь наклоняет ручной контроллер в нужном направлении.

02 / SENSING

MPU6050

Датчик считывает изменение положения и движения.

03 / PROCESSING

Arduino Nano

Микроконтроллер интерпретирует показания и формирует команду.

04 / COMMAND

Bluetooth

Команда передаётся роботу по Bluetooth-соединению.

CORE ELEMENTS / 03

01 / CONTROLLER

02 / SENSOR

03 / CONNECTION

04 / MOBILITY

Гусеничное шасси

Механическая основа мобильного робота.

05 / DRIVE

Двигатели и драйвер

06 / MISSION

Исследование среды

COMMUNICATION / CURRENT STATUS

Connected by Bluetooth.

На данный момент робот использует Bluetooth для передачи команд. Страница не имитирует GPS-трекинг, Wi-Fi-связь, онлайн-телеметрию или удалённое управление — эти функции не заявлены как реализованные.
